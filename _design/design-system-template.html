Corporate Navy

Tokens, tipografia e componentes do template. Tudo aqui é a mesma CSS usada na landing page: mude um token e as duas vistas mudam juntas.

Cores

Navy domina (fundos escuros e texto), azul primário é ação, ciano é destaque. Categóricas servem para diferenciar serviços: ícone e tags do mesmo card usam a mesma cor.

Base de 4px. Seções com 96px verticais (80px nas compactas, 160px no CTA final). Container de 1280px com gutter de 32px (16px no mobile).

Botões e links

Sempre pílula. Primário com seta "→" para a ação principal. Ghost no escuro, outline no claro. No máximo dois botões lado a lado.

Tags

Texto na cor categórica e fundo da mesma cor a 10%. Em fotos, use .tag--dark.

Como pedir ao Claude

Anexe este arquivo e use um pedido nesta linha. Quanto mais conteúdo real você der, menos o Claude inventa.

Use o arquivo design-system-template.html como base obrigatória.
1. Troque os tokens de marca: navy=#____, primary=#____, accent=#____.
   Fontes: títulos ____, corpo ____ (Google Fonts).
2. Marca: nome "____", subtítulo "____".
3. Mantenha estas seções, nesta ordem: hero, clients, problem, services,
   cases, results, cta, footer. Remova as demais.
4. Conteúdo de cada seção: [cole aqui os textos, números e cases].
5. Respeite as regras do GUIA PARA O CLAUDE no topo do arquivo
   (alternância de fundos, classes existentes, sem travessão, textos curtos).
6. Entregue um único HTML, sem frameworks, mantendo o JS do template.
